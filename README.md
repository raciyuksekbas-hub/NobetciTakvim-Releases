# NöbetçiTakvim

Avukatlar için iş ve süre takip uygulaması. *Her iş, vaktinde.*

**Bu depo yalnız dağıtım paketlerini içerir; kaynak kod içermez.**

## İndir

Son sürüm: [Releases](../../releases/latest)

| Platform | Dosya |
| --- | --- |
| macOS (Apple Silicon) | `NobetciTakvim-<sürüm>-arm64.dmg` |
| Windows (x64) | `NobetciTakvim.Setup.<sürüm>.exe` |

macOS paketleri Apple Developer ID ile imzalı ve Apple tarafından notarize
edilmiştir. Windows paketi kod imzasızdır; SmartScreen ilk kurulumda uyarı
gösterebilir.

Her sürümün notlarında dosyaların SHA-256 özetleri yayımlanır.
